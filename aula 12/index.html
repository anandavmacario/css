Content (conteúdo)

Define a largura da caixa (salvo elementos de bloco)

Padding (preenchimento)

Separa o conteúdo das bordas da caixa. É a margem interna

Border (Borda)

Define ordas para a caixa

Margin (Margem)

Define a distância entre uma caixa e outra

Width (Largura)

A largura total da caixa, por padrão é o somatório do conteúdo + padding (left/right) + border (left/right)

Height (Altura)

A altura total da caixa, por padrão é o somatório do conteúdo + padding (top/botton) + border (top/botton)
